# ⏱️ 실전 토익 모의 타이머 & 시험장 시계 (TOEIC Exam Simulator)

실제 정기시험 시험장 시계 환경을 시뮬레이션하고, LC/RC 개별 풀이 및 120분 실전 풀이를 지원하는 토익 전용 타이머입니다.
`index.html` 한 파일로 동작하며, PC·태블릿·스마트폰 브라우저 어디서나 인터넷 없이 사용할 수 있습니다.

---

## 📌 주요 특징 (Key Features)

1. **가상 시험장 시계**
   - 언제 연습하든 시작 버튼을 누르는 순간 시계가 시험 시작 시각부터 흐릅니다.
     - 오전 시험: 10:10 시작 (RC만 풀기는 10:55 시작)
     - 오후 시험: 15:10 시작 (RC만 풀기는 15:55 시작)
   - 시험장 앞 아날로그 벽시계를 보며 푸는 현장감 구현
   - 남은 시간(카운트다운)과 경과 시간을 함께 표시

2. **모드별 풀이 환경**
   - **전체 풀이 (LC + RC 연속 120분):** 실전 감각 및 집중력 유지 훈련. 45분이 지나면 자동으로 RC로 전환됩니다.
   - **LC만 풀기 (45분):** 음원과 함께 흘러가는 시험장 시계 역할만 합니다. (파트별 알림 없음)
   - **RC만 풀기 (75분):** 파트별 시간 배분 및 타임어택 훈련

3. **RC 맞춤형 시간 관리 (12-10-25-25 알림)**
   - **Part 5:** 12분 (잔여 63분에 알림)
   - **Part 6:** 10분 (잔여 53분에 알림)
   - **Part 7 단일:** 25분 (잔여 28분에 알림)
   - **Part 7 복합:** 25분 (잔여 3분에 알림)
   - **최종 검토/마킹:** 3분
   - 파트별 목표 시간을 분/초 단위로 바꿀 수 있고, 설정은 브라우저에 저장됩니다.

## 🎯 세부 기능 명세

### 1. 시작 설정
* 시험 시간대: `오전 (10:10 시작)` / `오후 (15:10 시작)`
* 풀이 영역: `전체 (120분)` / `LC만 (45분)` / `RC만 (75분)`
* RC 구간 설정 (LC만 풀기에서는 숨김)
* 알림: 비프음 켜기/끄기, 화면 테두리 깜빡임 켜기/끄기, 소리 테스트

### 2. RC 파트 진행 방식
* 목표 시각이 되면 다음 파트로 **자동 전환**되고 알림이 울립니다.
* 목표보다 빨리 끝냈다면 **`다음 파트로`** 버튼을 눌러 먼저 넘어갈 수 있습니다.
  - 실제로 끝낸 시각과 목표보다 얼마나 빨랐는지 기록됩니다.
  - 체크포인트 시각은 고정이므로 아낀 시간은 다음 파트로 넘어갑니다.
  - 이미 앞서 진행 중이면 해당 체크포인트에서는 소리 없이 안내만 표시합니다.
* 실수로 넘겼다면 **`되돌리기`** 버튼으로 직접 넘긴 파트를 취소할 수 있습니다. (일시정지 중에도 가능)
  - 이미 그 파트의 목표 시각이 지났다면 되돌린 뒤 바로 "시간 종료"로 다시 넘어갑니다.
* 마지막 파트(최종 마킹)에서는 버튼이 **`시험 끝내기`**로 바뀝니다. 확인 후 그 자리에서 시험이 끝나고 시계가 멈춥니다.
  - 남은 시간을 다 쓰면 알림과 함께 자동으로 끝납니다.

### 3. 화면 구성
* **아날로그 벽시계:** 가상 시험장 시각 (시/분/초침)
* **디지털 전광판:** 현재 파트, 남은 시간 `HH:MM:SS`, 시험장 시각, 경과 시간, 현재 파트 목표까지 남은 시간, 진행률 바
* **체크포인트 목록:** 파트별 목표 시각, 통과하면 녹색으로 표시
* **컨트롤:** 다음 파트로, 되돌리기, 일시정지/계속하기, 소리 켜기/끄기, 전체 화면, 그만하기

## 🛠️ 기술 구성

* **단일 파일:** HTML + CSS + Vanilla JavaScript (`index.html`), 외부 라이브러리 없음
* **정확한 시간 계산:** 시작 시각 기준으로 `Date.now()` 차이를 계산해, 탭이 백그라운드에 있어도 시간이 밀리지 않음
* **사운드:** Web Audio API로 비프음 직접 합성 (시작 버튼을 누를 때 오디오 활성화)
* **화면 꺼짐 방지:** Screen Wake Lock API (지원 브라우저에서만)
* **설정 저장:** localStorage
* **반응형:** 폰 세로/가로, 태블릿, 데스크톱 전체 화면 대응
