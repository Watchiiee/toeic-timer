# ⏱️ 실전 토익 모의 타이머 & 시험장 시계 (TOEIC Exam Simulator)

실제 정기시험 시험장 시계 환경을 시뮬레이션하고, LC/RC 개별 풀이 및 120분 실전 풀이를 체계적으로 지원하는 토익 전용 타이머 프로그램입니다. 

---

## 📌 주요 특징 (Key Features)

1. **실제 시험장 아날로그/디지털 시계 모드**
   - 오전 시험(10:10 시작) 및 오후 시험(15:10 시작)의 실제 시계 흐름 연동
   - 시험장 전면 시계를 보며 문제 푸는 현장감 구현
   - 남은 시간(Countdown) 및 경과 시간(Stopwatch) 동시 표기

2. **모드별 유연한 풀이 환경 지원**
   - **Full Test 모드 (LC + RC 연속 120분):** 실전 감각 및 집중력 유지 훈련
   - **LC 전용 모드 (45분):** 파트별 스키밍 및 집중 듣기 훈련
   - **RC 전용 모드 (75분):** 파트별 시간 배분 및 타임어택 훈련

3. **RC 맞춤형 시간 관리 (12-10-25-25 알림 시스템)**
   - 목표 점수 달성을 위한 황금 시간 배분 공식 탑재:
     - **Part 5:** 12분 (남은 시간 63분 전환 알림)
     - **Part 6:** 10분 (남은 시간 53분 전환 알림)
     - **Part 7 단일:** 25분 (남은 시간 28분 전환 알림)
     - **Part 7 복합:** 25분 (남은 시간 3분 종료 버퍼 알림)
     - **최종 검토/마킹:** 3분
   - **개인화 옵션:** 파트별 목표 시간 커스텀 변경 기능 및 무음/알림 토글 지원

| 시각 | 단계 | 세부 내용 및 안내 |
| :---: | :---: | :--- |
| **09:20** | 권장 입실 | 고사장 입실 완료 권장 |
| **09:50** | **입실 통제** | 이후 고사장 출입 절대 불가 (지각 처리) |

| **09:45 ~ 10:05** | 휴식 및 신분 확인 | 수험표 및 신분증 대조 확인, 전자기기 수거 |
| **10:05 ~ 10:10** | 문제지 배부 | 문제지 수령 및 파본 확인 (인쇄 상태 점검) |
| **10:10 ~ 10:55** | **LC (듣기)** | **45분간 음원 재생 및 풀이 (Part 1~4)** |
| **10:55 ~ 12:10** | **RC (읽기)** | **75분간 풀이 (Part 5~7)** |
| **12:10** | 시험 종료 | 문제지 및 답안지 회수, 매수 확인 후 퇴실 |

| **15:55 ~ 17:10** | **RC (읽기)** | **75분간 풀이** |

## 🎯 세부 기능 명세 (Specifications)

### 1. 시험 모드 선택 (Initial Setup)
* **시험 시간대 선택:**
  - `오전 시험 (10:10 시작)`
  - `오후 시험 (15:10 시작)`
* **풀이 영역 선택:**
  - `전체 풀이 (LC 45분 + RC 75분 = 120분)`
  - `LC만 풀기 (45분)`
  - `RC만 풀기 (75분)`

### 2. RC 구간 알림 설정 (RC Interval Manager)
* **프리셋 (Default Preset): 12 - 10 - 25 - 25 공식**
  - **1차 알림 (12분 경과 / 잔여 63분):** Part 5 종료 ➔ Part 6 진입 권장
  - **2차 알림 (22분 경과 / 잔여 53분):** Part 6 종료 ➔ Part 7 단일지문 진입 권장
  - **3차 알림 (47분 경과 / 잔여 28분):** Part 7 단일 종료 ➔ Part 7 복합지문 진입 권장
  - **4차 알림 (72분 경과 / 잔여 3분):** 풀이 종료 및 미마킹/세모 문제 최종 마킹 점검
* **커스텀 설정 (Customization):**
  - 파트별 분/초 단위 직접 입력 및 수정 가능
  - 시각적 점멸 알림(화면 깜빡임), 비프음(사운드 알림), 무음 토글 제공

### 3. 디스플레이 화면 구성 (UI Layout)
* **상단:** 시험장 스타일 아날로그 벽시계 (시/분/초침 구동)
* **중앙:** 디지털 전광판 스타일 표시
  - 현재 파트 (예: `Part 7 복합지문 풀이 중`)
  - 남은 시간 카운트다운 (`HH : MM : SS`)
  - 전체 시험 진행률 바 (Progress Bar)
* **우측/하단:** 
  - RC 구간별 체크포인트 인디케이터 (통과 시 녹색 전환)
  - 일시정지, 재시작, 파트 건너뛰기 컨트롤 버튼

## 🛠️ 권장 기술 스택 (Tech Stack)

* **프론트엔드 단일 파일 구현 (Single-Page App):**
  - HTML5, Tailwind CSS, Vanilla JavaScript (또는 React Single File)
* **사운드 효과:** Web Audio API (외부 의존성 없는 자체 비프음 합성)
* **반응형 디자인:** 태블릿, 모바일, 데스크톱 모니터 전체 화면(F11) 완벽 대응
